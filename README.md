# 🐾 萌獸大進擊

可愛動物塔防網頁遊戲：5 張地圖、50 關、18 種炮塔（最高 Lv4）、每 10 關大 BOSS，第 20 關起 BOSS 會從路徑中間突襲。

## 遊玩
- 電腦：直接用瀏覽器打開 `index.html`
- 手機 / 平板：開啟 GitHub Pages 網址

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面結構 |
| `style.css` | 外觀樣式 |
| `js/data.js` | 炮塔、動物、BOSS、地圖、關卡數值（調難度改這裡） |
| `js/audio.js` | 音效與背景音樂（即時合成，不需音檔） |
| `js/game.js` | 遊戲引擎與畫面 |
| `js/main.js` | 選單、商店、天賦、存檔 |
